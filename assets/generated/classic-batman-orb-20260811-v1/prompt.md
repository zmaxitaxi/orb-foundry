# Batman orb asset prompt

Create an original pixel-art circular orb body for a browser battle game. The asset is a complete round dark charcoal/black orb with a bold bright-white pixel outline, an angular black eye-mask with white eyes, and a gold utility belt wrapping across the lower middle. Use crisp nearest-neighbor pixel edges and a flat `#00ff00` chroma-key background for cleanup. Do not include HP, numbers, text, logos, watermark, human body, limbs, or a separate orb underneath. The exported final must be transparent outside the circular orb.

The generated image was accepted from the built-in GPT image generator, then keyed with `remove_chroma_key.py` using the border color and soft matte/despill settings.
